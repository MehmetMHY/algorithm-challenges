# Web Works

## About

This repository contains a collection of **web development resources, notes, and mini projects** designed to help developers build modern web applications. Whether you're working with databases, JavaScript runtimes, or popular npm packages, you'll find curated lists of essential tools and libraries that power today's web development ecosystem. In this directory/repository:

## What's Inside

- **Database Solutions**: Docker-ready database setups for PostgreSQL, MySQL, and MongoDB
- **Runtime Environments**: Modern JavaScript runtimes and package managers
- **Essential NPM Packages**: Carefully selected packages for querying, API development, and tooling
- **Mini Projects**: Hands-on examples including Sequelize implementations and authentication workflows

## Great Sources

- **Databases:** [postgres](https://hub.docker.com/_/postgres), [mysql](https://hub.docker.com/_/mysql), & [mongodb](https://hub.docker.com/_/mongo)
